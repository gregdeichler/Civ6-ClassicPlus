# Architecture and evidence

Classic+ is an add-on to `RULESET_EXPANSION_2`. It uses the game's existing leader domains, trait definitions, and assets. The only required dependency is Gathering Storm; an installed Rise and Fall or leader DLC can contribute its own content without being required for the add-on. No mod action writes the leader selection table.

- `Configuration/GatheringStorm.sql` changes the Gathering Storm victory domain and Dramatic Ages setup row. It runs in the frontend before ruleset selection, with SQL predicates restricting its scope.
- `Gameplay/Ages/Disable.sql` removes the two age-related capabilities and zeros historic moment score while preserving eras. Taj Mahal gains a steady Culture yield. Dark Age policies retain their age requirement, so this does not make powerful age policies available as ordinary wildcard cards.
- `Gameplay/WorldCongress/Disable.sql` removes Congress and emergency capabilities, delays regular sessions beyond all stock eras as a second guard, defaults diplomatic victory off, and replaces or neutralizes several Favor rewards. Promise requests no longer cost Favor, so this change does not make requests unaffordable. Ordinary diplomatic actions and grievance consequences are retained.
- `Gameplay/LeaderCompatibility/Abilities.sql` updates existing trait attachments, effects and conditions, including conditional updates for DLC-dependent rows. `Localization/en_US.xml` updates affected English strings. `UI/` wraps installed Gathering Storm scripts for the two age controls whose stock UI keys off chronological eras. It carries no stock XML, art, or Lua.
- `Tools/` builds a deterministic archive from the manifest and applies the SQL to disposable copies of clean debug databases. The game itself applies the manifest, runs the Lua, and evaluates the engine's rules.

## Sources inspected

- [Gathering Storm Demo Mod project](https://github.com/mikepmerritt/Civ-6-Mods/tree/master/Gathering%20Storm%20Demo%20Mod) confirms the DLC ID and frontend/gameplay action split. [BBG's modinfo](https://github.com/CivilizationVIBetterBalancedGame/BetterBalancedGame/blob/02fe6f5f9d009aad6325d8fae5126c3a206d70c9/BetterBalancedGame.modinfo) shows ruleset criteria and action load order.
- [Gathering Storm manifest and UI mirror](https://github.com/civfanatics/Civ6-UIFiles-Restructured/tree/1ebc67937a8b285e45c8bed777828e8b677ce529/DLC/Expansion2) shows the two UI contexts, control IDs, and hooks. This is source inspection, not a live UI test.
- [OneTrueBirdMod](https://github.com/hdpotter/OneTrueBirdMod) demonstrates postponing Congress with `WORLD_CONGRESS_INITIAL_ERA`. Its era thresholds alone leave dedications and age UI in place. [DB Civ 6 Multiplayer Gold](https://github.com/dbergan/db_civ6_gold/tree/0d4c49d4e3dfe391b05b3b582b73d47dbcac175c) demonstrates capability removal and the era-screen hook. Classic+ uses its own SQL and small wrappers.
- [Civilization VI Modding Wiki](https://jonathanturnock.github.io/civ-vi-modding/docs/) and [Civ modding tools](https://github.com/bmaupin/civ-modding-tools/blob/main/civilization-6/docs/development.md) provide database and log workflow references.
- [Gathering Storm debug database snapshot](https://github.com/nuanyuqingfeng/civ6-modding-skills/tree/e618aad0dea24af91ecd38d8b2300f8c1daff695/skills/civ6-modding/database) supplies the actual column names, capability IDs, stock trait wiring and setup domains tested here. The two snapshots were read outside this repository. There was no local SDK or game install to confirm platform-specific behavior.
